A custom made 65 % keyboard made with classical indian asthetics . it is made on royal indian theme . the microcontroller used is raspberry pi pico and pcb is designed in kicad and the case is designed in onshape  . 
--- 
# features - 
* rapberry pi pico
* custom case
* custom pcb
* made on royal indian design
* rotary encoder
* 65 % keyboard size
